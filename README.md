# TradeSim Qt

A cross-platform stock trading simulator built with C++17 and Qt 6.11

## Features
- Real-time stock price simulation (10 stocks)
- Buy/Sell trading engine with balance tracking
- Portfolio view with P&L calculation
- Trade history with timestamps
- Price chart per stock (tick-based)
- SQlite persistence via Qt SQL
